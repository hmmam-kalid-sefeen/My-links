# My Links

📌 A simple project to share all my product links with ease — no captchas, no annoying ads.

## 🚀 Live Demo
You can view the project here:  
👉 [https://my-links.vercel.app](https://my-links.vercel.app)

## 📂 Project Structure
- `pages/` → Next.js pages
- `posts/` → JSON files for blog articles
- `public/` → Static assets (images, icons, etc.)
- `package.json` → Dependencies and scripts

## ⚡ Features
- Clean and simple design
- Markdown support for blog posts
- Fast deployment with Vercel
